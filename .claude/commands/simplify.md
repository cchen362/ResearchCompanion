# Simplify Code Command

Analyze and simplify the provided code or the currently selected code in the editor.

## Instructions:

1. If code is selected in the IDE, simplify that code
2. If no code is selected, ask the user to provide code to simplify
3. Focus on:
   - Reducing complexity
   - Improving readability
   - Following best practices
   - Removing redundancy
   - Optimizing performance

Provide both the simplified version and an explanation of the changes made.
